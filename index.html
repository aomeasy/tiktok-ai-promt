ตัวช่วยสร้างสคริปต์ + prompt สำหรับ Google Flow

กรอกรายละเอียดสินค้าครั้งเดียว ระบบจะประกอบเป็น prompt ภาษาอังกฤษ 3 ฉาก (Hook, Reveal, Demo) พร้อมวางลง Google Flow ได้ทันที ทุกฉากกำกับให้ AI อ้างอิงรูปสินค้าจริงที่แนบไว้ (product reference image) เพื่อให้หน้าตา สี และพื้นผิวของสินค้าในคลิปตรงกับของจริงที่ขาย — จึงไม่ต้องพิมพ์ระบุสี/วัสดุเองอีกต่อไป ให้ AI ดูจากรูปแทน และกำกับไม่ให้มีข้อความ/ซับไตเติล/ตัวอักษรใด ๆ ติดในภาพ (จะไปใส่ซับไตเติลเองทีหลังใน CapCut) หมายเหตุ: ช่องที่ระบุ "ส่งให้ AI" ต้องกรอกเป็นภาษาอังกฤษ เพราะโมเดลวิดีโอเข้าใจ prompt ภาษาอังกฤษเท่านั้น ส่วนช่องภาษาไทยใช้แสดงผลในหน้านี้และเป็นซับไตเติลเท่านั้น ไม่ถูกส่งเข้า prompt

เช่น "portable handheld mini fan" — ใส่แค่ชื่อประเภทสินค้าพอ ไม่ต้องระบุสี/วัสดุ เพราะให้ AI ดูจากรูปอ้างอิงที่แนบแทน คำนี้จะถูกใส่ใน prompt จริง ห้ามเว้นว่าง

ฉาก 01 · 0-5 วิ

Hook — เปิดฉากดึงความสนใจ

ใช้จุดขายหลักของสินค้าเป็นแรงจูงใจฉาก (ไม่ใช่ข้อความในภาพ) เพื่อดึงความสนใจใน 3 วินาทีแรก

ฉาก 02 · 5-11 วิ

Reveal — โชว์สินค้าใกล้ ๆ

หมุนช้า ๆ โชว์พื้นผิวและรายละเอียด ไม่มี action ซับซ้อนให้ AI ทำพลาดง่าย

ฉาก 03 · 11-17 วิ

Demo — ใช้งานจริง

โชว์ท่าออกกำลังกายเพื่อสร้างความน่าเชื่อถือและปิดการขาย

ซับไตเติลแนะนำ (ใส่เองใน CapCut)

ก่อนวางลง Google Flow — เช็ค aspect ratio เป็น 9:16 ทุกครั้งก่อนกด generate (ค่ามักรีเซ็ตเป็น 16:9) และเลือกโหมดวิดีโอ/Veo ไม่ใช่ Imagen เพราะสองโหมดนี้แยกกัน ทุกฉาก (Hook/Reveal/Demo) ต้องแนบรูปสินค้าจริงเป็น reference image ก่อน generate เสมอ เพื่อให้สินค้าที่ออกมาตรงกับของจริงที่ขาย ส่วนหมวดสัตว์เลี้ยง/ผู้สูงอายุ ต้องแนบรูปสัตว์เลี้ยง/คนจริงเพิ่มอีกใบสำหรับฉาก Demo — ไม่ใช่แค่ copy prompt ไปวางเฉย ๆ

โหมด ASMR: เหมาะกับสินค้าที่มีพื้นผิวให้ "สัมผัส" ทางสายตาชัดเจน (ผ้า ขนสัตว์ ยาง ซิลิโคน โฟม) ถ้าสินค้าผิวเรียบมันวาว (เช่น พลาสติก/โลหะแข็ง) โทนนี้อาจดูไม่เข้ากับสินค้าเท่าไร ลองสลับดูทั้งสองโหมดแล้วเทียบผลลัพธ์

ทุก prompt ในหน้านี้ปิดท้ายด้วยคำสั่งห้ามมีตัวอักษร/ซับไตเติล/โลโก้ในวิดีโอแล้ว (no on-screen text, no captions, no subtitles, no watermark, no logos) แต่โมเดลวิดีโอบางตัวยังหลุดใส่ตัวอักษรเบลอ ๆ มาได้เอง ให้เช็คคลิปที่ได้ทุกครั้งก่อนตัดต่อ ถ้ายังมีตัวอักษรติดมา ให้ generate ใหม่หรือครอปฉากนั้นออก

ก่อนโพสต์ทุกคลิป: เปิดตัวเลือก "AI-generated content" ในหน้าอัปโหลดเสมอ — ตั้งแต่ 21 ก.ค. 2026 TikTok บังคับติด label เปิดเผยเนื้อหาที่สร้าง/แก้ด้วย AI จนดูสมจริง (ไม่ใช่แค่ในหมวด Shop แต่ครอบคลุมทุกคลิป/โฆษณาที่มีภาพ เสียง หรือวิดีโอสังเคราะห์ที่สมจริง เช่น ฉาก Demo ที่ animate จากรูปสัตว์เลี้ยง/คนจริงในหน้านี้) ไม่ติดป้ายมีความเสี่ยงถูกลบคลิปหรือแบนบัญชี และเช็คว่าฉากที่ generate ไม่ได้ทำให้สินค้าดูเวอร์เกินจริงเทียบกับของจริง โดยเฉพาะถ้าขายสินค้าหมวดสุขภาพ/ความงาม/ทำความสะอาด ซึ่งมีกฎเข้มกว่าหมวดอื่น
